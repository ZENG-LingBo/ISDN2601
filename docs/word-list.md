# Word list

One word for each thing, used the same way everywhere: in the app, the messages it writes for the group chat, the README and the deck. Apple's Human Interface Guidelines suggest keeping a list like this so the wording stays consistent.

| group | crew, gang | The group's own name can be anything, like "O-camp gang". |
| time, times | slot, slots | "Fri 27 Nov, evening" is one time. |
| free | available | "When are you free?" |

## Style

- Sentence case for every heading, button and label: "Start a plan", not "Start A Plan".
- Buttons start with a verb and say what happens: "Start a plan", "Copy message", "Confirm this time".
- Talk to the reader as "you". Use "we" only in messages that a person sends to their friends.
- Numbers as numerals: "3 people", not "three people".
- Dates as "Fri 27 Nov", times of day as "lunch", "afternoon" or "evening".
- No emoji in the interface.
- Error messages say what happened and what to do: "Someone in this group is already called Mei. Try adding your last initial."
