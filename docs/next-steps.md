## Decisions for you

- **Totals before a plan is confirmed.** The app shows how many people are free at each time before a plan is confirmed. That helps people find a time, but friends can sometimes guess someone's answer from those numbers. [`docs/review-log.md`](review-log.md) (cycle 15) shows how often this happens. You could hide the totals until the plan is confirmed. The class test interview asks which people prefer.
- **QR code for check-in.** Check-in uses a 4-digit code. A QR code would need a downloaded library, and Claude Code's safety check blocked adding it. Tell Claude if you want it added.
- **A fuller accessibility scan.** The axe-core tool would check every screen more thoroughly. Claude Code's safety check blocked running the downloaded tool. Tell Claude if you want it run.
