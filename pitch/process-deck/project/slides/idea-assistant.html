Idea 2 of 6: an assistant inside the group chat

When someone writes “we should hang out”, an assistant in the chat offers to run the plan.

How it works for Mandy

  1. Mei writes “we should hang out”. The assistant asks, “Want me to find a time?”
  2. Each friend tells it in private when they’re free, and what they can’t eat or afford.
  3. It posts 3 options everyone can do, and confirms the one most people pick.

The second idea moves the planning into the chat itself. Nobody opens a new app. The assistant notices the message, and each friend tells it in private what works for them, including food and money limits. It solves the most pain points of any idea. There are two problems. It reads the chat, which hurts privacy. And a student team can't add it to the chat apps people use today. So I can only show it as a mock-up.
